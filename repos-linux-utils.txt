# Linux apps & utilities — gap-fillers for the wider archive
# Containers (Docker CE stack), media, SQLite, monitoring, diagnostics,
# backup/sync, and everyday CLI tools
#
# Purpose: offline Gitea mirror + local reference for AI coding agents
#
# Formats: owner/repo (GitHub) | https://host/owner/repo | https://host/owner/repo.git
#
# Notes:
#   - Docker CE is assembled from Moby + CLI + containerd + runc (+ BuildKit/Compose)
#   - FFmpeg official canonical remote is git.ffmpeg.org; GitHub mirror is fine for archiving
#   - SQLite canonical SCM is Fossil; sqlite/sqlite is the official git mirror
#   - Monitoring split that works well in 2026:
#       Glances  = plugin/API breadth (containers, sensors, GPU, remote)
#       btop     = modern interactive TUI
#       nvtop    = cross-vendor GPU process monitor
#       LACT     = GPU tuning GUI (clocks, fans, power) for AMD/NVIDIA/Intel
