# Zed editor + extensions
# For offline mirror / Gitea archive and local AI-agent reference
#
# Built into Zed (no extension required for basic highlighting / editing):
#   Markdown (+ preview; Mermaid diagrams render in preview as of 2026)
#   YAML, XML, JSON, HTML, CSS
#   JavaScript, TypeScript (incl. JSX/TSX)
#   Python, Groovy, Makefile, Shell/Bash
#   SQL (baseline), Dockerfile (baseline), TOML (baseline)
#   C, C++, Go, Rust
#   and others listed at https://zed.dev/languages
#
# Extensions below add LSP depth, framework support, lint/format,
# themes, MCP, or stronger language tooling beyond those built-ins.
#
# Formats: owner/repo (GitHub) | https://host/owner/repo | https://host/owner/repo.git

# Core
# ============================================================
