# ============================================================
# Tier 1 hardening — high efficacy for exposed self-host stacks
# ============================================================
# Practical pattern:
#   1) WireGuard for admin/management access (shrink public surface)
#   2) Caddy or nginx + CrowdSec bouncer on the public edge
#   3) Authentik (or Authelia) for app SSO
#   4) fail2ban for simple daemon jails CrowdSec does not cover
#   5) Vaultwarden for credentials

crowdsecurity/crowdsec                   # Collaborative IPS — scenarios + shared signals + bouncers
                                         # Often the best fail2ban upgrade at a reverse-proxy edge
fail2ban/fail2ban                        # Classic log-based IP bans (SSH and simple services)
goauthentik/authentik                    # SSO / IdP (full-featured)
Authelia/authelia                        # Lighter SSO / portal auth alternative
dani-garcia/vaultwarden                  # Bitwarden-compatible password manager
WireGuard/wireguard-tools                # WireGuard userspace tools
WireGuard/wireguard-linux                # WireGuard kernel components (full source if desired)
