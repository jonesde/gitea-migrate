# Foundational technology gems
# Internet specs (bottom-up by layer), crypto primitives, then Bitcoin/Lightning
#
# Purpose: offline Gitea mirror + local reference for AI coding agents
#
# Formats: owner/repo (GitHub) | https://host/owner/repo | https://host/owner/repo.git
#
# ============================================================
# Layer model (approximate mapping used in this file)
# ============================================================
# Classical OSI 7 layers (for orientation) vs practical Internet stack:
#
#   L1 Physical        — media, signaling (mostly IEEE / hardware; little useful public git)
#   L2 Data Link       — Ethernet, Wi-Fi MAC (mostly IEEE standards, not convenient git)
#   L3 Network         — IP, ICMP, routing (BGP/OSPF/…)
#   L4 Transport       — TCP, UDP, QUIC
#   L5 Session         — connection/session patterns (thin in IP stack; partly TLS/app)
#   L6 Presentation    — encoding, crypto framing (TLS, codecs; crypto libs live here-ish)
#   L7 Application     — HTTP, DNS app usage, web standards, mail, OAuth, …
#
# This file is ordered BOTTOM-UP: L1/L2 notes → L3 → L4 → crypto/TLS → L7
# → tooling → other protocol networks → language RFCs → Bitcoin/Lightning last.
#
# ============================================================
# git vs non-git resources (read this before expanding the archive)
# ============================================================
# Many foundational specs are NUMBERED RFCs or IEEE standards, not git monorepos.
#
#   RFC corpus (strongly recommended companion to this list):
#     - https://www.rfc-editor.org/  (official text / XML / PDF)
#     - Bulk download / mirror from rfc-editor.org
#     - Tooling: ietf-tools/xml2rfc (below)
#
#   Suggested minimum RFC offline set (examples):
#     L3:  791 (IPv4), 8200 (IPv6), 4443 (ICMPv6), 1918, 6890
#     L4:  793 / 9293 (TCP), 768 (UDP); QUIC RFCs after drafts matured
#     DNS: 1034, 1035, 6891 (EDNS), 8484 (DoH), 7858 (DoT)
#     TLS: 8446 (TLS 1.3) + related BCPs
#     HTTP: 9110–9114 family
#     URI/IDNA: 3986, 5890/5891
#     OAuth history: 6749, 6750, 7636 (PKCE), 9700 (security BCP)
#                   → current consolidation direction: oauth-wg/oauth-v2-1
#     Mail (optional): 5321, 6409
#
#   IEEE L1/L2 (802.3 Ethernet, 802.11 Wi-Fi, etc.):
#     - Not convenient as open git “spec repos”
#     - Expand with external IEEE docs if normative L1/L2 text is required
#
#   IETF WGs are multi-repo orgs. This file picks highest-value active repos
#   (not entire tlswg / oauth-wg / quicwg orgs).
